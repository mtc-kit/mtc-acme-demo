ACME, in your browser.

Request a certificate from an experimental MTC ACME server using an ML-DSA-65 account.

Experimental demo — use test accounts only. The account’s private seed is stored in a JavaScript-readable, first-party cookie for one year. Anyone with access to this browser or this origin’s scripts can use it. The cookie is also sent to this page’s host, so serve this app only from an origin you trust. No proxy or backend performs ACME requests.

Certificate signing request

The certificate key is separate from the ML-DSA account key. Pasted CSRs must use an ML-DSA-44, ML-DSA-65, or ML-DSA-87 key; RSA, ECDSA, HashML-DSA, and other algorithms are rejected.

Save the certificate private key now. It is not stored in a cookie and will be lost on reload. It is never sent to the ACME server.
